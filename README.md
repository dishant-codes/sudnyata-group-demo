# Contact Form Design with Tailwind CSS

This project features a **modern website** built using **Tailwind CSS**. The form is responsive, visually appealing, and designed for easy integration into your web pages.

## Features

- **Responsive Design**: The layout adjusts seamlessly across different screen sizes (mobile, tablet, and desktop).
- **Tailwind CSS**: Utilizes utility-first classes for quick and efficient styling.
- **Clean UI**: Focus on minimalism and user-friendly design.
- **Hover Effects**: A smooth hover effect on the submit button.
- **Accessibility**: Proper use of labels and form controls for enhanced accessibility.

## Live Demo

You can view the live demo of this contact form on (https://dishant-codes.github.io/sudnyata-group-demo/).

## Tech Stack

- **HTML**: Structure of the page.
- **Tailwind CSS**: Styling of the page using utility-first classes.
- **Responsive Layout**: Adjusts for mobile, tablet, and desktop.
